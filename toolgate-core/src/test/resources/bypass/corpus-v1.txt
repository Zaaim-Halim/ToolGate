# ToolGate bypass corpus, format version 1.
#
# One case per line:  kind | expect | input | why
#   kind    url        UrlCheck with schemes http and https, any public host, default ports
#           url-hosts  UrlCheck with schemes https, hosts mycompany.com and *.mycompany.com
#           path       PathCheck with under($R) and notUnder($R/secret), against a fixture:
#                        $B/data/reports/q3.csv               a file
#                        $B/data/reports/secret/salaries.csv  excluded by notUnder
#                        $B/data/reports/link -> $B/outside   symlink out of the root
#                        $B/data/reports/latest.csv -> q3.csv symlink inside the root
#                        $B/data/reports/drop.csv -> $B/outside/missing.csv  dangling symlink
#                        $B/data/reports/shared.csv           hard link to $B/outside/key.txt
#                        $B/data/reports-old/x.csv            sibling with a shared prefix
#                        $B/outside/key.txt                   outside every root
#                      $R is $B/data/reports.
#   expect  allow or deny
#   input   the argument, exactly as a model would write it; \uXXXX escapes stand for one
#           character, so this file stays ASCII and nothing in it is invisible
#   why     the trap, or the source of the case
#
# Every reported bypass becomes a case here before its fix is merged. Never edit a case to make
# it pass; add a new format version instead if the meaning of a field must change.
